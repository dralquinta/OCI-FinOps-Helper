Command definitions for Claude Code development in this repository.

| Skill | Command File | Description |
|---|---|---|
| development | [development.md](development.md) | Use when the user asks to implement repository changes with strict test-driven development, optional spec-driven development, parallel agent coordination, structured clarification and planning, and disciplined validation and commit hygiene. |
| graphify | [graphify.md](graphify.md) | Use when the user asks to build, refresh, query, explain, or operationalize a Graphify knowledge graph for this repository. |
| perseus | [perseus.md](perseus.md) | EXPERIMENTAL: Use when the user asks to wire, explain, or operationalize Perseus Vault local-first agent memory, or to combine Perseus memory with the graph for durable, cross-session learning. |
